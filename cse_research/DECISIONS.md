| 2026-10-11 | Retain all 6 extreme daily return shock events (|return| > 8%) without truncation, winsorization, or deletion. | Verified via historical archive records that all 6 dates correspond to real political elections, constitutional crises, and macroeconomic default events. | Winsorize returns at ±5% or 3 standard deviations; drop shock days as outliers. |
| 2026-10-11 | Group 36 raw Elections.csv rows into 24 distinct election events in `events_event_level` while preserving provincial breakdown and multi-province stage records in `events_stage_level`. | Provincial Council elections conducted concurrently share announcement and polling dates; grouping creates clean event-level units while preserving exact provincial detail and staggered formation dates. | Maintain 36 rows with duplicate event dates; or flatten multi-province elections into single rows and discard differing formation dates. |
| 2026-10-11 | Map event dates to the first open CSE trading day on or after the date ($M \ge D$) using `cse_clean`. Save both raw date, mapped date, and `gap_days`. | Many polling days occur on Saturdays (or Sundays) when markets are closed; market reaction cannot occur before the first subsequent trading session opens. | Map to preceding trading day; or ignore non-trading day events. |
| 2026-10-11 | Parse 'Not Available' strictly as missing (`NaN` / `None`) for nomination dates in Row 3 (Wayamba 2004 PC) and Row 16 (Western 2009 PC). Never interpolate or guess dates. | Mandatory Rule R1 (Real data only) and Rule R11 (Never invent facts). Preserves historical data integrity. | Impute average nomination duration (e.g. 10 days before poll); search unverified internet sources. |
| 2026-10-11 | Flag events within $\pm 30$ trading days of another distinct election (`has_overlap_poll_30td` and `is_overlapping_30td`). Do not drop any overlapping events. | Identifies event clustering (e.g. April 2004 Parliamentary and Wayamba PC 12 trading days apart; Sept-Nov 2024 Presidential and Parliamentary elections) to guide multi-event controls in Stage 3 Event Study. | Drop overlapping elections from analysis; shorten event window to 5 days. |
| 2026-10-11 | Provide `data/raw/events_supplement_TEMPLATE.csv` for missing proposal-referenced events (Local Government elections, Cabinet reshuffles) and support loader merging with `added_by_researcher = True`. | Strict adherence to Rule R1 and Rule R11. Proposal names March/May 2025 LG polls and cabinet transitions not present in Elections.csv; they must not be added from memory without sourced documentation. | Add unverified dates from memory; ignore proposal-referenced event categories. |
| 2026-10-11 | Establish 5 expanding-window walk-forward phases (P1: val 2012–14, P2: val 2015–17, P3: val 2018–20, P4: val 2021–23, P5: val 2024–25) with a mandatory 10-trading-day embargo gap before each validation window. | Prevents forward-looking leakage on horizons up to $h=5$ days, eliminates lookahead bias, and mirrors the research proposal's 2009–2025 focus with expanding historical training starting in 1994. | Rolling fixed-window; standard K-fold cross validation (strictly prohibited by Rule R2). |
| 2026-10-11 | Reserve validation blocks strictly for evaluation. Hyperparameters tuned only inside each training window using an inner chronological split (last 15% of training window, with its own 10-day embargo). | Guarantees validation blocks remain genuinely untouched out-of-sample data, eliminating hyperparameter snooping and overfitting. | Tune hyperparameters on validation blocks; use random split within training window. |
| 2026-10-11 | Model Selection Decision Rule: Primary = Out-of-sample $R^2$ of 5-day log return ($h=5$) versus expanding historical-mean forecast AND Diebold-Mariano test with HLN correction vs random walk ($p < 0.05$); Secondary = balanced accuracy; model must beat baselines in $\ge 3$ of 5 phases; ties resolved by simplicity. | Follows econometric best practices (Campbell-Thompson 2008, Goyal-Welch 2008) where beating the historical mean out-of-sample is the gold standard for return predictability; Diebold-Mariano verifies statistical significance. | Select on RMSE or direction accuracy alone; select based on in-sample fit. |
| 2026-10-11 | Evaluate 5-day overlapping targets on all daily validation sliding points using Newey-West HAC standard errors (lag bandwidth $q = h-1 = 4$), supplemented by non-overlapping weekly subsamples (every 5th trading day). | Overlapping daily stepping maximizes sample efficiency and preserves full granularity of event reactions, while Newey-West HAC and non-overlapping subsamples control for serial autocorrelation in prediction errors. | Discard all overlapping days; evaluate only non-overlapping weekly blocks. |
| 2026-10-11 | Adopt a fixed-parameter, daily input-advancing inference protocol as the primary evaluation standard, with an optional 63-trading-day (quarterly) sensitivity refit protocol. | In realistic operational quantitative finance, models are not re-estimated on every single day due to turnover costs, latency, and overfitting risks. 63-day refitting serves as a sensitivity check. | Re-estimate model weights on every trading day (computationally prohibitive, high turnover); or train only once on P1 and never expand. |
| 2026-10-11 | Enforce standardized artifact directory structure `models/<family>/<model>/<phase>/` storing binary model, `meta.json` (seeds, library versions, hardware, data hash, dates), and pointer to prediction file. | Rule R6 and Rule R7 mandate exhaustive auditability and zero-screen-only artifacts. | Save flat models without metadata; save only prediction files without serialized model weights. |
| 2026-10-11 | Adopt Constant-Mean Return Model ($L_{est} = 15$ trading days) as the primary Event Study design, ending strictly 1 day before the event window $[w_1 - L_{est}, w_1 - 1]$ to guarantee zero overlap. Repeat with $L_{est} \in \{60, 120\}$ for robustness. | Direct proposal design (Section 3.2). 15 days is short and sensitive to local market drift; 60- and 120-day windows provide statistical stability against return noise. | Use single fixed estimation window; or overlap estimation window with event window (severe lookahead violation). |
| 2026-10-11 | Implement S&P SL 20 Market Model sensitivity check strictly for events after 2012-06-27 with explicit caveat that ASPI is the broader market and SP20 constituents overlap ASPI. | Sensitivity check following proposal Section 3.3. Cannot serve as primary model because ASPI is the total market index and S&P SL 20 did not exist prior to June 2012. | Back-cast S&P SL 20 prior to 2012 (violates Rule R1); or omit market model sensitivity entirely. |
| 2026-10-11 | Establish multi-tier statistical significance framework for single index event study: Brown-Warner t-stat, 10,000-draw non-event placebo permutation test, Wilcoxon signed-rank, Sign test, and Benjamini-Hochberg FDR correction. | Single index time series cannot rely on cross-sectional firm-level independence; 10,000 placebo draws from 5,297 clean non-event days capture actual emerging market fat tails and volatility clustering. | Rely solely on asymptotic normal assumptions; ignore multiple testing false discovery rate. |
| 2026-10-11 | Mandate small-sample warning ($n < 5$) and report both full sample and non-overlapping subsamples ($\pm 30$ trading days) for all CAAR aggregations. | Sri Lanka had only 5 Presidential elections (2000-2024); reporting statistical significance without $n$ and overlap controls leads to false academic claims (Rule R8 honest reporting). | Pool all elections without distinction; drop overlapping events without reporting full sample. |
| 2026-10-11 | Implement reusable `prior_event_stats` module that filters strictly on events whose full window concluded prior to `as_of_date` ($\text{window\_end\_date} < \text{as\_of\_date}$). | Guarantees that future event study features used in subsequent ML forecasting stages (Stage 5+) cannot leak future election reactions into past training windows. | Calculate full-sample CAR features in advance and merge across all historical dates (severe lookahead leakage). |
| 2026-10-12 | Omit subjective political direction and outcome sentiment labels from Feature Set C. Retain only strictly causal pre-event calendar and stage features. | Direct adherence to Rule R1 (Real data only) and Rule R2 (Zero lookahead). No documented, objective pre-event index of political orientation exists for Sri Lankan parties without outcome bias and hindsight revisionism. | Hand-assign arbitrary left/right or pro-market labels with outcome knowledge (strictly prohibited). |
| 2026-10-12 | Mask S&P SL 20 features (`sp20_log_return`, `aspi_sp20_spread`) with `NaN` prior to 2012-06-27 inception. Impute with neutral constant (0.0) in Phase P1 training pipeline where SP20 was unobserved. | Preserves real historical market structure without backward synthesis. Binary indicator `has_sp20 = 0` explicitly alerts models to index unavailability. | Synthesize S&P SL 20 backward to 1994 via regression; or drop S&P SL 20 entirely from feature matrix. |
| 2026-10-12 | Causal Event As-Of Horizon: An election is strictly unknown before `announcement_date_mapped`. For active events, the most recent stage is tracked. Event cycle concluded if > 30 trading days elapse after final stage (`government_formation` / `result`). | Matches event study bounds ([0, +30]) and prevents premature knowledge of elections before official gazetting proclamation. | Use calendar election dates before announcement; or keep events permanently active indefinitely. |
| 2026-10-12 | Generate deep sequence tensors (N, L, D) for L in {20, 60, 120} strictly within split boundaries (N - L + 1 samples) without crossing phase boundaries or into embargo gaps. | Eliminates lookback leakage into preceding training or embargo blocks during validation and inner-validation evaluation. | Pad initial sequence steps with out-of-split observations; or cross into the 10-day embargo gap. |
| 2026-10-12 | ARIMA fitted on daily log returns with d=0 (AIC order selection p,q <= 3 on training window only). Stationary I(0) per ADF (p < 0.001) and KPSS evidence. Mathematically equivalent to ARIMA(p, 1, q) on log levels. | Guaranteed stationarity prevents explosive unit-root dynamics and non-invertible MA roots during walk-forward forecasting. | Fit ARIMA on non-stationary log index levels; use arbitrary fixed (p, d, q) orders. |
| 2026-10-12 | SARIMA evaluated with weekly cycle m=5 (5 trading days/week) and monthly sensitivity m=21. Honest reporting: seasonal AR/MA terms are not statistically significant (p > 0.10, Ljung-Box shows white noise); daily returns exhibit negligible trading-cycle seasonality. | Direct protocol requirement. Captures potential day-of-week calendar effects while honestly documenting that CSE returns follow a near-martingale difference sequence. | Enforce forced seasonality without significance testing; omit monthly sensitivity check. |
| 2026-10-12 | Restrict VAR on (ASPI return, SP20 return, log turnover) strictly to post-2012 phases (P2–P5). Omit Phase P1 due to pre-2012 S&P SL 20 inception date (2012-06-27). | Strict adherence to Rule R1 (no synthetic backfill of non-existent indices). Preserves historical data veracity. | Synthetically back-cast SP20 before 2012; drop VAR entirely. |
| 2026-10-12 | Volatility models (GARCH, EGARCH, GJR-GARCH) evaluated strictly on variance metrics: Patton (2011) QLIKE loss, MSE of realized variance, MAE of volatility, and Mincer-Zarnowitz R2. Direction accuracy strictly excluded. | Volatility models forecast second moments (conditional variance), not conditional mean return direction. Direction accuracy is methodologically invalid for variance estimators. | Score GARCH on direction accuracy (invalid); evaluate only in-sample. |
| 2026-10-12 | Shallow ML hyperparameter tuning governed by fixed budget (3 configurations per family) evaluated strictly on the inner-validation slice (last 15% of training window, 10-day inner embargo). Classifier probabilities calibrated via Platt scaling (1D logistic regression) fitted on inner-val slice. | Prevents hyperparameter snooping on outer validation blocks (Rule R2). Platt calibration yields well-calibrated posterior probabilities P(Up) without lookahead. | Tune on outer validation sets; use uncalibrated tree probabilities. |
| 2026-10-12 | Multitask dual-head deep sequence architecture predicting both $y_{\text{ret}}$ (Huber loss, $\delta=0.01$) and $y_{\text{dir}}$ (Binary Cross Entropy with Logits) jointly via loss $L = L_{\text{Huber}} + 0.5 \cdot L_{\text{BCE}}$. | Joint representations allow shared latent sequence features to capture both magnitude and sign while regularizing against overfitting on the small ~7,600 row dataset. | Train two completely separate neural networks for each target (doubles training time and storage without mutual regularization). |
| 2026-10-12 | Select lookback length $L \in \{20, 60, 120\}$ strictly on the inner-validation slice (last 15% of each training window, guarded by 10-day inner embargo) via probe trials prior to multi-seed walk-forward fitting. | Strict adherence to Rule R2 (Zero lookahead). Outer validation blocks must never be used to choose lookback window length. | Pick arbitrary fixed lookback for all models; choose lookback based on outer validation performance (lookahead violation). |
| 2026-10-12 | Reversible Instance Normalization (RevIN, Kim et al., ICLR 2022) integrated with affine parameters along sequence dimension; evaluated systematically with and without RevIN across all 11 model architectures. | Financial time series exhibit non-stationary distribution shifts across market regimes. RevIN removes local instance mean/std before sequence encoding and restores scale post-representation, mitigating distribution shifts. | Standard batch normalization or layer norm only; static dataset-wide z-score standardization only. |
| 2026-10-12 | Automated trivial-predictor collapse detection: flag model runs as collapsed if predicted return standard deviation $< 10^{-4}$ or directional prediction ratio $> 98\%$ or $< 2\%$. | Rule R3 / Constant Predictor mandate. When markets have positive drift (e.g. Phase P5 recovery rally), a collapsed network that simply predicts a trivial positive constant will show apparent ~61% direction accuracy without learning any predictive signal. Flagging collapsed runs prevents false positive claims. | Report raw direction accuracy of collapsed constant networks as valid; omit collapse monitoring. |
| 2026-10-12 | Pretrained foundation model live verification audit under Rule R11: Chronos-Bolt (`amazon/chronos-bolt-tiny`, 9M, Apache-2.0) and TimesFM (`google/timesfm-2.5-200m-pytorch`, 200M, Apache-2.0) verified, downloaded, and evaluated. Moirai (`uni2ts`) skipped due to strict incompatible pins (`torch==2.4.1`, `numpy==1.26.4`, `pandas==2.1.4`). Lag-Llama skipped because GluonTS 0.14+ C++ compilation is unsupported on Windows x86_64. | Mandatory Rule R11 verifiable open-source mandate. Prohibits fake imports or synthetic weight claims. Evaluates real installable foundation models and honestly logs technical blockers for skipped ones. | Falsify unavailable foundation models with synthetic random walks; or omit foundation model testing entirely. |
| 2026-10-12 | Chronos-Bolt selected over legacy Chronos-T5 as primary Chronos representative based on live inference profiling (~0.65ms/step vs ~62ms/step, 100x speedup). Direct quantile regression heads avoid slow autoregressive token sampling. | Chronos-Bolt was explicitly designed by Amazon (2024) to replace autoregressive T5 architectures with direct quantile outputs, reducing latency by two orders of magnitude while preserving probabilistic distribution estimation. | Run slow autoregressive T5 on CPU across all 60 configurations; or drop Chronos family entirely. |
| 2026-10-12 | Systematic stationarity comparison: Foundation models evaluated on both stationary log-returns and non-stationary log-levels across context lengths $L \in \{64, 256, 512\}$. Non-stationary log-levels cause catastrophic drift ($R^2 < -0.20$), whereas stationary returns achieve positive OOS $R^2$ (up to $+0.072$ in P3). | Empirical demonstration of time-series econometric principles: foundation models trained across mixed-domain data struggle with unnormalized random-walk unit-root drift. Log-return differencing guarantees mean-reversion and bounded error variance. | Restrict evaluation to returns only without testing levels; or evaluate levels without stationarity diagnosis. |
| 2026-10-12 | Text-LLM weak baseline evaluated with temperature 0, recent 20-day numeric return history only, structured JSON schema validation, and disk caching. Prominent contamination disclosure documented: general LLMs memorised historical CSE behavior during pretraining, so older periods (P1–P4) are contaminated and cannot serve as clean out-of-sample evidence. | User mandate and Rule R8 honest reporting. General LLMs have public web memory of historical market movements, invalidating standard OOS claims. Explicitly labelling as a weak, contaminated baseline prevents misleading marketing assertions. | Omit Text-LLM baseline; or claim LLM results represent valid, uncontaminated forecasting skill. |
| 2026-10-12 | ARIMA + LSTM residual hybrid architecture: ARIMA(1, 0, 1) captures linear autocorrelation; lightweight LSTM (32 units, lookback 20) models non-linear residual dynamics. Trained strictly on in-sample training residuals with inner chronological validation slice (last 15% of training window) for early stopping. | Classical linear + non-linear decomposition (Zhang 2003). Preserves econometric interpretability in the backbone while capturing non-linear volatility and momentum clustering in residuals without lookahead. | Fit LSTM on raw returns alone; or train residual corrector on validation residuals (lookahead leakage). |
| 2026-10-12 | Stacked ensemble with Ridge meta-learner ($\alpha=1.0$) trained strictly on out-of-fold (OOF) predictions generated by 3 inner chronological walk-forward splits within each training window (with 10-day embargoes). Validation predictions are NEVER exposed to the meta-learner during training. | Mandatory Rule R2 zero-lookahead mandate. Standard K-fold stacking or fitting meta-learners on validation predictions causes severe optimistic bias and lookahead leakage. Inner chronological OOF training mirrors genuine production deployment. | Train meta-learner on outer validation predictions; or use unregularized linear regression that overfits multicollinear base forecasts. |
| 2026-10-12 | Stage 9 Model Selection: Select `CatBoostRegressor` on Feature Set C (`iterations=80, depth=4, lr=0.05`) as the Global Champion Model following the pre-registered selection rule hierarchy.
