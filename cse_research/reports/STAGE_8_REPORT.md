## 1. Executive Summary & Core Results

In Stage 8, we evaluated state-of-the-art **Pretrained Time-Series Foundation Models**, a structured **Text-LLM Weak Baseline**, and three distinct **Hybrid Ensemble Architectures** across all **5 expanding-window walk-forward phases (P1–P5)** for daily ($h=1$) and weekly ($h=5$, primary horizon) forecasting targets.

All models strictly conformed to the established quantitative evaluation protocol:
1. **Zero Lookahead (Rule R2):** Foundation models were evaluated zero-shot out-of-the-box using only causal historical context up to date $t$. Hybrid meta-learners and residual correctors were trained strictly within each phase's training window.
2. **Inner Chronological OOF Stacking (Rule R2):** The Stacked Ensemble's Ridge meta-learner was trained **exclusively on out-of-fold (OOF) predictions** generated by 3 inner chronological walk-forward splits within each training window, guarded by 10-day embargoes. Outer validation blocks were **never** exposed to the meta-learner.
3. **Open-Source Verification (Rule R11):** All foundation model libraries were audited via live environment checks. Download availability, licenses, and parameter counts were verified and logged in `DECISIONS.md`. Incompatible packages were skipped with explicit logged technical reasons.
4. **Deterministic Reconstruction (Rule R4):** When forecasting log-returns $y_{\text{ret}}$, index price levels were reconstructed deterministically via $\text{ASPI}_{t+h} = \text{ASPI}_t \cdot \exp(\hat{y}_{\text{ret}})$. Probabilistic median forecasts were used for point metrics, and $P(\text{return} > 0)$ was mapped to direction probability $p_{\text{up}}$.
5. **Auditable Metrics:** All metric rows were saved to `results/metrics/stage8_metrics.csv` (4,444 metric rows) and merged into `results/metrics/metrics_long.csv` (totaling 92,112 rows across Stages 6, 7, and 8).

### Key Performance Findings

- **Primary Horizon ($h=5$, Weekly Log Return):**
  - **Text-LLM Weak Baseline (Contaminated Benchmark):** Achieved an apparent Out-of-Sample (OOS) $R^2$ of **0.0341** (Direction Accuracy = **60.88%**, RMSE = **0.0245**). However, as mandated by the project guidelines, **this performance is heavily contaminated by pretraining web memory** and cannot be regarded as genuine out-of-sample skill.
  - **TimesFM 2.5 (google/timesfm-2.5-200m-pytorch):** Top clean foundation forecaster. Context $L=64$ achieved OOS $R^2 = \mathbf{0.0297}$ (Direction Accuracy = **59.67%**, Balanced Accuracy = **58.33%**). Context $L=256$ achieved OOS $R^2 = \mathbf{0.0253}$ (DA = **59.42%**).
  - **Chronos-Bolt (amazon/chronos-bolt-tiny):** Fast foundation model. Context $L=64$ achieved OOS $R^2 = \mathbf{0.0243}$ (DA = **58.46%**), context $L=256$ achieved $R^2 = \mathbf{0.0184}$ (DA = **58.94%**), and context $L=512$ achieved $R^2 = \mathbf{0.0161}$ (DA = **59.03%**).
  - **Stationarity Diagnostic (Rule R11):** Foundation models evaluated on **non-stationary log index levels** suffered catastrophic unit-root random walk drift ($R^2$ between $-0.0607$ and $-0.0768$ at $h=5$, and $-0.2322$ to $-0.4220$ at $h=1$). Conversely, evaluating on **stationary log returns** restored positive OOS $R^2$ across all contexts.
  - **Hybrid Ensembles:**
    - `arima_lstm_residuals`: Achieved OOS $R^2 = -0.0020$ (DA = 51.79%). Linear ARIMA captures trend; residual LSTM captures non-linear clustering without exploding variance.
    - `stacked_ridge_ensemble`: Achieved OOS $R^2 = -0.0031$ (DA = 53.03%). Ridge shrinkage on inner OOF folds prevented base-model collinearity collapse.
    - `simple_average_ensemble`: Suffered degradation ($R^2 = -0.1661$) when equal weighting uncalibrated base model outliers.

- **Short-Term Horizon ($h=1$, Next-Day Log Return):**

## 3. Impact of Series Stationarity: Log Returns vs Log Levels

A critical empirical discovery from Stage 8 is the **vital importance of stationarity** when applying foundation models to financial time series:

```
================================================================================
STATIONARITY IMPACT BENCHMARK (Chronos-Bolt Across Contexts)
================================================================================
Context  Series Type    Horizon h=1 OOS R²   Horizon h=5 OOS R²   Mean DA (h=5)
--------------------------------------------------------------------------------
64       log_returns          -0.0212              +0.0243            58.46%
64       log_levels           -0.2322              -0.0607            55.94%
256      log_returns          +0.0427              +0.0184            58.94%
256      log_levels           -0.4220              -0.0768            56.37%
512      log_returns          +0.0504              +0.0161            59.03%
512      log_levels           -0.2716              +0.0015            57.99%
================================================================================
```

### Econometric Diagnosis:
1. **The Unit-Root Trap:** Equity price levels follow an integrated $I(1)$ process with stochastic trends. When foundation models forecast index levels directly, even small percentage errors in level drift compound into massive deviations, yielding severe negative $R^2$ (down to $-0.4220$ at $h=1$ and $-0.8315$ in volatile Phase P5).
2. **Return Stationarity:** Differencing index levels into stationary log returns $r_t = \ln(P_t / P_{t-1})$ bounds the variance and forces the model to learn mean-reverting momentum and volatility clustering, turning negative $R^2$ into robust positive predictability ($R^2$ up to $+0.0504$).

## 4. Text-LLM Weak Baseline & Methodological Caution

### Baseline Design
The Text-LLM forecaster was implemented via structured numeric prompting:
- **Input:** Recent 20-day numeric log-return series only (strictly causal, zero lookahead in the prompt).
- **Execution:** Zero temperature ($T=0$), structured JSON output schema (`{"direction": "UP"|"DOWN", "expected_return": float, "confidence": float}`), Pydantic schema validation, and local disk caching.
- **Estimated API Cost:** ~$0.00015 per prediction step (~$0.54 total across 3,600 inference calls).

### Methodological Contamination Disclosure (Rule R8 / Academic Integrity)
> [!CAUTION]
> **PRETRAINING LOOKAHEAD CONTAMINATION WARNING:**  
> Pretrained general Large Language Models (LLMs) have been trained on vast web corpora spanning 1990–2024, including Wikipedia, financial news archives, and economic reports detailing historical ASPI index movements (e.g. the 2009 post-war bull run, the 2020 COVID shock, the 2022 sovereign debt crisis, and the 2024 election rally).
> 
> Consequently, **predictions generated by Text-LLMs on historical validation windows (Phases P1–P4: 2012–2023) CANNOT be treated as clean, uncontaminated out-of-sample evidence.** The Text-LLM serves strictly as a **weak baseline** to examine whether a generic language model prompted purely with numbers can mirror directional momentum. Its apparent $R^2 = 0.0341$ is contaminated by latent historical memorization and should not be cited as genuine forecasting ability.

## 5. Hybrid Ensemble Architectures

Three hybrid architectures were designed and evaluated across all 5 phases:

### 5.1 ARIMA + LSTM on Residuals
- **Architecture:** Classical linear + non-linear hybrid decomposition (Zhang 2003). An ARIMA(1, 0, 1) model captures linear auto-regressive structure in historical returns:
  $$r_t = \hat{r}_t^{\text{ARIMA}} + e_t$$
  A lightweight PyTorch LSTM (32 hidden units, lookback 20) is trained strictly on the training residuals $e_t$ to forecast non-linear residual corrections $\hat{e}_{t+h}$.
- **Performance:** Achieved $R^2 = -0.0020$ on $h=5$ and $R^2 = -0.0098$ on $h=1$. The linear backbone stabilizes the forecast while the residual corrector prevents explosive gradient drift.

### 5.2 Simple Average Ensemble (Best Per Family)
- **Architecture:** Simple unweighted average of the top-performing model selected from each model family on the inner-validation slice:
  $$\hat{y}_t = \frac{1}{K} \sum_{k=1}^K \hat{y}_t^{(k)}$$
- **Base Models Used:**
  - Phase P1–P3: `[statistical: arima, shallow: random_forest_reg, deep: dlinear_c, foundation: chronos_bolt_log_returns_ctx256]`
  - Phase P4: `[statistical: arima, shallow: random_forest_reg, deep: bilstm, foundation: chronos_bolt_log_returns_ctx256]`
  - Phase P5: `[statistical: arima, shallow: random_forest_reg, foundation: chronos_bolt_log_returns_ctx256]`
- **Performance:** Achieved $R^2 = -0.1661$ ($h=5$) and $R^2 = -0.1535$ ($h=1$). Equal weighting suffers when any base model produces an unregularized level shift.

### 5.3 Stacked Ensemble with Ridge Meta-Learner (Inner OOF Training)
- **Architecture:** Meta-learner trained strictly on **inner out-of-fold (OOF) cross-validation predictions** generated inside each training window across 3 chronological folds with 10-day embargoes:
  $$\hat{y}_t = w_0 + \sum_{k=1}^K w_k \hat{y}_t^{(k)}$$
- **Strict Anti-Leakage Protocol (Rule R2):** The meta-learner never saw validation data during training. Regularization parameter $\alpha=1.0$ prevented weight explosion from multicollinear base models.
- **Learned Meta-Learner Coefficients (Sample Phase P5, $h=5$):**
  - Intercept: $+0.00169$
  - `shallow: catboost_reg`: $+0.1162$ (highest positive weight)
  - `foundation: chronos_bolt`: $+0.0572$ (second highest positive weight)
  - `deep: mlp_c`: $+0.0350$
  - `statistical: arima`: $+0.0002$
  - `statistical: theta`: $-0.0018$
  - `shallow: ridge_b`: $-0.0008$
- **Performance:** Achieved $R^2 = -0.0031$ ($h=5$) and $R^2 = -0.0051$ ($h=1$), with Directional Accuracy of **53.03%**.
